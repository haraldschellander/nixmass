# Package index

## All functions

- [`hs2swe()`](https://haraldschellander.github.io/nixmass/reference/hs2swe.md)
  : A model which translates snow depth observations to snow water
  equivalents
- [`hsdata`](https://haraldschellander.github.io/nixmass/reference/hsdata.md)
  : Daily snow depth data for a northern alpine station
- [`nixmass()`](https://haraldschellander.github.io/nixmass/reference/nixmass.md)
  : SWE modeling with the delta.snow process based model and several
  empirical regression models.
- [`plot(`*`<nixmass>`*`)`](https://haraldschellander.github.io/nixmass/reference/plot.nixmass.md)
  : Plot modeled SWE values of a nixmass object.
- [`summary(`*`<nixmass>`*`)`](https://haraldschellander.github.io/nixmass/reference/summary.nixmass.md)
  : Print summary of a nixmass object.
- [`swe.delta.snow()`](https://haraldschellander.github.io/nixmass/reference/swe.delta.snow.md)
  : SWE modeling from daily snow depth differences
- [`swe.gu19()`](https://haraldschellander.github.io/nixmass/reference/swe.gu19.md)
  : Statistical SWE modeling based on a quadratic dependance on the
  day-of-year
- [`swe.jo09()`](https://haraldschellander.github.io/nixmass/reference/swe.jo09.md)
  : Statistical SWE modeling depending on month and climatic region in
  Switzerland
- [`swe.pi16()`](https://haraldschellander.github.io/nixmass/reference/swe.pi16.md)
  : Statistical SWE modeling depending on the day-of-year
- [`swe.st10()`](https://haraldschellander.github.io/nixmass/reference/swe.st10.md)
  : Statistical SWE modeling depending on day of year and a climatic
  region
